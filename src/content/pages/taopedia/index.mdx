**Taopedia** is a lightweight, wiki-style site that organizes knowledge into interlinked articles. Each article is a Markdown/MDX file with frontmatter defining title, categories, optional summary, and an infobox. The site renders a table of contents and supports backlinks and search.

## Overview

- **Content location:** articles live under `src/content/pages/` (one folder per page with an `index.m(d)x`).
- **Routing:** each article is available at `/wiki/<slug>` via `src/pages/wiki/[...slug].astro`.
- **Infobox:** pages can define `infoboxTitle`, `infoboxCaption`, `infoboxImage`, and `infoboxRows` in frontmatter; the layout assembles and renders them.
- **Categories:** set `categories: ["..."]` in frontmatter; shown at the bottom of each article.
- **Search:** a search UI is available at `/search` and uses a static index when built for production.

## Content Structure

Frontmatter adheres to the `pages` collection schema in `src/content/config.ts`:

- **Required:** `title`
- **Optional:** `slug`, `categories`, `summary`, `redirects`, `draft`, `featured`
- **Infobox (optional):** `infoboxTitle`, `infoboxImage`, `infoboxCaption`, `infoboxRows` (array of `{ label, value }`)

Example fields are visible in pages like `src/content/pages/earth/index.mdx`, `src/content/pages/moon/index.mdx`, and `src/content/pages/gravity/index.mdx`.

## Editing and History

The article layout (`src/pages/wiki/[...slug].astro`) exposes quick links:

- **Edit:** opens the corresponding file on the repository host.
- **History:** links to `/wiki/<slug>/history` (if available in your project tooling).
- **What links here:** shows backlinks when `public/data/backlinks.json` is present.

## Internal Links and Backlinks

- Use double brackets to link between pages, e.g. `[[Earth]]`, `[[Moon]]`, `[[Gravity]]`.
- A link graph and backlinks can be generated by project scripts that output `public/data/backlinks.json` and `public/data/slugmap.json` used by the layout.

## Examples

- [[Earth]] — overview of our home planet
- [[Moon]] — Earth's natural satellite
- [[Gravity]] — the interaction governing planetary motion and tides
