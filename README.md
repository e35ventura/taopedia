# Taopedia

Taopedia is a Bittensor-focused knowledge base built with Astro and deployed on Netlify.

This repository contains the website application: layouts, routing, search, build scripts, and deployment config. Article content is maintained in the companion repository:

https://github.com/e35ventura/taopedia-articles

## How The Two Repositories Work

- `taopedia` is the Astro app that Netlify builds and hosts.
- `taopedia-articles` is the public MDX content repo where contributors add and edit articles.
- During `npm run dev` and `npm run build`, `scripts/sync-articles.js` copies Bittensor-focused articles from `taopedia-articles` into `src/content/pages`.
- `src/content/pages` is generated build content and is intentionally ignored by Git in this repo.
- When article changes land in `taopedia-articles/main`, the live site is rebuilt from the latest approved content.

## Local Development

Clone both repositories next to each other:

```bash
git clone https://github.com/e35ventura/taopedia.git
git clone https://github.com/e35ventura/taopedia-articles.git
cd taopedia
npm install
npm run dev
```

The expected local layout is:

```txt
parent-folder/
  taopedia/
  taopedia-articles/
```

If the articles repo lives somewhere else, set `TAOPEDIA_ARTICLES_DIR`:

```bash
TAOPEDIA_ARTICLES_DIR=/path/to/taopedia-articles npm run dev
```

Visit:

```txt
http://localhost:4321
```

## Build

```bash
npm run build
```

The build pipeline:

1. Syncs Bittensor-focused MDX articles from `taopedia-articles`.
2. Generates article history data.
3. Builds link graph and category data.
4. Builds the static Astro site into `dist`.
5. Builds the Pagefind search index.

Preview the production build:

```bash
npm run preview
```

## Content Rules

Most content work should happen in `taopedia-articles`, not here.

Articles are included on Taopedia when they are Bittensor-focused. The sync script includes articles when:

- the slug is `taopedia`;
- `tags` includes `Bittensor`;
- or `category` is one of `Bittensor`, `Consensus`, `Staking`, `Subnets`, `Tokenomics`, or `Wallets`.

Article front matter in `taopedia-articles` uses `category` and `tags`; the app converts those fields into Astro `categories` during sync.

## Deployment

Netlify builds this repository from `main`.

Current settings:

```txt
Build command: git fetch --unshallow || true && npm run build
Publish directory: dist
Node version: 20
```

Article changes are deployed after they are reviewed, merged, and the site rebuild completes.
